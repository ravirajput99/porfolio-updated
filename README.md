## How to Use

1. Open `index.html` in your browser — it's a standalone static site, no build step required.
2. Add your own photos under `assets/images/`.
3. Update `index.html` content (links, projects, bio) as your career grows.
4. Deploy anywhere static hosting is supported: Netlify, Vercel, GitHub Pages, Cloudflare Pages, etc.

## Deploy (Quick Options)

- **Netlify**: Drag and drop the folder onto [netlify.com/drop](https://netlify.com/drop).
- **Vercel**: Connect your GitHub repo and import the project.
- **GitHub Pages**: Push to a repo, enable Pages in Settings, point to the root folder.

## Tech Behind the Design

- Semantic HTML5
- CSS with custom properties (dark mode by default, respects `prefers-color-scheme`)
- Vanilla JavaScript (no frameworks — loads instantly)
- Inter + JetBrains Mono fonts from Google Fonts
